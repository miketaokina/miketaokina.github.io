- Q: How to clone a repository from GitHub to local machine?
  - A: 
    1. cd ~/your local workspace
    2. git clone ssh address of your repository
    3. cd your local workspace repository
    4. code .

- Q: How to preview in local?
  - A: 
    1. cd ~/your local workspace
    2. in terminal: python3 -m http.server 8000
    3. Go to http://localhost:8000 in your browser
    4. Control + C to terminate
  - Or:
    1. in VS Code: Cmd + Shift + X
    2. Search and install Live Server(By Ritwick Dey)
    3. Open file: index.html
    4. Right click: Open with Live Server in code editter or click Go Live Icon in down-right area
    5. http://127.0.0.1:5500 will be opened in your default browser
